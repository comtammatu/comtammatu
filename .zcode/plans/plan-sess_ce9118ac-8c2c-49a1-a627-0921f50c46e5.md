# Kế hoạch: Đổi `/finance/supplier-invoices` sang mô hình VAT cộng xuôi (additive), đơn giá = NET

## Quyết định & phân loại
- **Quyết định chủ:** Đơn giá = NET (chưa VAT), chuẩn HĐĐT VN. VAT cộng xuôi. Tổng tiền = net + VAT. Bỏ selector "Cách nhập giá". Có đụng DB.
- **Tier: T3** (tiền bạc + multi-row correctness + schema migration). Đăng ký `REVIEW_TIER=T3`.
- **Mô hình mới (additive):**
  - `net_line_total = round(qty × unit_price − line_discount, 2)` (đơn giá nhập = NET)
  - `vat_amount = round(net_line_total × vat_rate / 100, 2)` [auto] HOẶC nhập tay [manual]
  - `gross_line_total = net_line_total + vat_amount`  ← "Tổng tiền" (đã gồm VAT)
  - Bất biến DB `line_total = gross_line_total − vat_amount` **KHÔNG ĐỔI** (vì `line_total` vốn là net). → matching/valuation/price-history không bị ảnh hưởng.

## Tệp đụng (theo lớp)

### 1. Migration DB — tạo qua `node scripts/supabase-migration-new.mjs supplier_invoice_net_unit_price`
File mới `supabase/migrations/<ts>_supplier_invoice_net_unit_price.sql`, BEGIN/COMMIT:
- **Backfill `unit_price` = NET thật sự:** `UPDATE supplier_invoice_lines SET unit_price = round((line_total + line_discount_amount)/quantity, 2) WHERE quantity > 0;` (đảm bảo `unit_price` tái lập `line_total` khi trừ discount).
- **Đổi constraint trigger** `private.enforce_supplier_invoice_gross_contract()` → bất biến additive:
  - `line_total IS DISTINCT FROM greatest(round(quantity*unit_price − line_discount_amount, 2), 0)` → lỗi
  - `vat_amount > line_total` (khi rate>0) → lỗi; `vat_rate=0 ⇒ vat_amount=0`
  - `gross_line_total IS DISTINCT FROM (line_total + vat_amount)` → lỗi
  - Bỏ mọi nhánh `pricing_mode` và `gross_unit_price`.
- **Đổi RPC** `public.save_supplier_invoice_draft(...)`:
  - Bỏ 2 nhánh `pricing_mode` (extractive) → 1 đường additive.
  - Sửa `save_supplier_invoice_draft_unchecked` legacy-line map: giữ nguyên `unit_price` nhập + `line_discount` thật (hiện đang hardcode `line_discount=0` và re-derive `unit_price=line_total/qty` — phải sửa để lưu đúng đơn giá net + chiết khấu nhập).
  - Bỏ trường `pricing_mode` khỏi `jsonb_to_recordset`, bỏ `UPDATE ... SET pricing_mode, gross_unit_price`.
  - Giữ validation scale 2dp, `gross = subtotal + vat`, header match.
- **Xóa cột chết:** `DROP COLUMN pricing_mode`, `DROP COLUMN gross_unit_price` (+ 2 CHECK constraints tương ứng). Lý do: đơn giá net là nguồn sự thật duy nhất, không để cột mồ côi (per AGENTS.md "delete cleanly").
- **Giữ** `gross_line_total` (cần cho tổng header + bất biến).
- Chạy `corepack pnpm lint:migration-lineage`; snapshot `git status --short -- supabase/migrations` để đảm bảo không trùng batch.
- **Không tự apply.** Production apply chỉ khi chủ ủy quyền trong phiên (`supabase-production-push.mjs --dry-run` → `--apply`). Sau apply: `corepack pnpm db:types`.
