`docs/agent/rules/`. Claude Code may read `CLAUDE.md` automatically, so this
file is kept as a stable pointer only. Do not duplicate project rules here. If
anything conflicts, `AGENTS.md` and the applicable files under
`docs/agent/rules/` win.

Read `AGENTS.md` (and the rule files it names) before any implementation work.
