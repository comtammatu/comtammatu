# Release `1.2.0.2` — Web-Standard Hardening (robots.txt + security.txt) (2026-05-09)

> **Patch on top of `1.2.0.1`.** Two thin static-asset additions targeting external crawlers and security researchers. No end-user behavior change. Tag: `1.2.0.2`.

## What changed

| Artifact | Path | Purpose |
|----------|------|---------|
| `robots.txt` | `apps/web/app/robots.ts` (Next.js MetadataRoute) | Block search engines from indexing private/auth-gated paths |
| `security.txt` | `apps/web/public/.well-known/security.txt` (RFC 9116) | Standard vulnerability-disclosure contact |

## Why robots.txt

The QR feedback flow at `/r/<token>` issues short-lived (rotatable) tokens. If Googlebot indexes a deep link today, that URL goes dead the next time the QR is rotated — leaving a "404 Not Found" in the Google Search index that hurts SEO health AND leaks the existence of the feedback feature without a useful landing.

Cycle 1 commit `939be3d9` already makes invalid `/r/<token>/thank-you` return 404 (phishing-vector close), and the parent `/r/<token>` page calls `notFound()` for inactive tokens. `robots.txt` complements this by telling crawlers not to bother following any `/r/` URL in the first place.

While we're at it, also block:
- `/admin/`, `/api/`, `/login`, `/access-denied` — auth-gated, no SEO value.
- `/employee/`, `/br/`, `/notifications`, `/orders`, `/menu`, `/inventory/`, `/payment/` — internal POS / KDS / inventory surfaces.

The marketing/landing pages (when they exist) live at `/` and are NOT in the disallow list.

## Why security.txt

[RFC 9116](https://www.rfc-editor.org/rfc/rfc9116) defines a well-known location at `/.well-known/security.txt` where security researchers can find the project's contact + disclosure policy. Some bug-bounty platforms (HackerOne, Bugcrowd) also auto-discover this file.

Required fields shipped:
- `Contact: mailto:comtammatu@gmail.com` — project's canonical contact.
- `Expires: 2027-05-09T00:00:00.000Z` — 12-month validity. RFC 9116 §2.5.5 recommends ≤ 1 year so the contact stays fresh.
- `Preferred-Languages: vi, en` — Vietnamese first (project is VN-based), English secondary.
- `Canonical: https://app.comtammatu.com/.well-known/security.txt` — anti-forgery anchor.
