## Tests added (143 → 147)

`packages/shared/src/feedback/__tests__/regressions.test.ts` is new this patch and contains 4 source-text regression tests that read the implementation source and assert the cycle's guards are still in place. A future refactor that drops a guard fails the test before it reaches CI:

1. `actions-photos.ts updates photo_paths with the conditional .or() guard` — locks `FEEDBACK-PHOTO-PATHS-CONDITIONAL-UPDATE`.
2. `/r/[token]/thank-you/page.tsx 404s for invalid or inactive tokens` — locks `FEEDBACK-THANK-YOU-MUST-NOTFOUND-INVALID` (with a tightened builder-chain regex from `4543fab1`).
3. `actions.ts uses after() (not fire-and-forget) for telegram-flush + AI enrich` — locks `FEEDBACK-AFTER-NOT-FIRE-AND-FORGET`.
4. `next.config.ts emits all security headers + disables X-Powered-By` — locks `SECURITY-HEADERS-IN-NEXT-CONFIG` (with HSTS preload value baked in).

`packages/shared/src/feedback/__tests__/schemas.test.ts` also gained 1 test for `ISSUE-008`'s distinct error messages.
