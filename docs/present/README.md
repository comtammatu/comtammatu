# Presentations

This folder contains communication artifacts such as standalone HTML decks.
These files are historical/contextual material for discussion and review.
They are not runtime authority and do not define architecture, routes, schema,
or UI behavior.

Current runtime and implementation authority lives in `AGENTS.md`,
`docs/agent/rules/`, `docs/CODEBASE_MAP.md`, `docs/modules/`, `docs/spec/`,
`tasks/regressions.md`, and `tasks/todo.md`.
